## Synthesis implication
Every major coding harness converged independently on: declarative file-based TYPE (markdown/YAML frontmatter: description-for-routing, tool allowlist, model tier, MCP servers) + ephemeral INSTANCE spawned per task in isolated context/worktree, stateless unless memory opted in. No standard covers internal agent-class definitions portable across harnesses — a portable worker-class card would combine A2A-style capabilities with harness frontmatter fields.

## Leads
- Anthropic harness design research on Planner/Generator/Evaluator (swarms issue #1500)
- Copilot SDK Fleet Mode docs (parallel dispatch semantics)

## Gaps
- No rigorous public benchmarks isolating which role decompositions pay off vs add overhead
- No instance pooling/warm-worker evidence — all surveyed harnesses spawn ephemeral instances
